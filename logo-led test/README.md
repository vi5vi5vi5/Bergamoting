# ledlab — подсветка Станции Мини 3

Две программы на Go:

- **`ledd`** — агент на колонке. Управляет кольцом логотипа (6 RGB-зон) и
  сегментами часов, отдаёт HTTP API и страницу с кнопками на порту `8765`.
  Уступает подсветку Алисе, пока та показывает свою анимацию, и возвращает
  своё после.
- **`ledctl`** — утилита для компьютера: по SSH собирает, заливает,
  запускает и останавливает агента.

Как устроена подсветка и откуда взялось такое решение — [docs/leds-research.md](docs/leds-research.md).

## Запуск

```sh
go run ./cmd/ledctl deploy     # собрать ledd под arm64, залить в /data/opt/bin и перезапустить
go run ./cmd/ledctl status     # pid, память, кто сейчас управляет подсветкой
go run ./cmd/ledctl logs       # лог агента (/tmp/ledd.log на колонке)
go run ./cmd/ledctl stop       # остановить: подсветка вернётся прошивке
```

Адрес колонки по умолчанию — `192.168.1.12`, SSH `2222`; другой задаётся флагами:
`go run ./cmd/ledctl -host 192.168.1.50 -ssh 2222 deploy`.

Страница с кнопками: http://192.168.1.12:8765

Агент не стартует сам после перезагрузки колонки — запустите `ledctl start`.

## API

Описание типов — [internal/api/api.go](internal/api/api.go). Примеры:

```sh
curl http://192.168.1.12:8765/api/state
curl -X POST http://192.168.1.12:8765/api/ring  -d '{"color":"#ff0000"}'
curl -X POST http://192.168.1.12:8765/api/ring  -d '{"zones":[0,3],"brightness":40}'
curl -X POST http://192.168.1.12:8765/api/clock -d '{"text":"12:34"}'
curl -X POST http://192.168.1.12:8765/api/clock -d '{"segments":{"G0":true,"DH":false}}'
curl -X POST http://192.168.1.12:8765/api/ring/release
curl -X POST http://192.168.1.12:8765/api/clock/release
curl -N http://192.168.1.12:8765/api/events   # поток состояния (SSE)
```

API открыт всей локальной сети без пароля — как и SSH колонки.

## Что известно о поведении

- Прошивка перерисовывает время в начале каждой минуты; агент возвращает свои
  сегменты примерно через 0,1 с, поэтому раз в минуту время коротко мигает.
- После анимации Алисы кольцо возвращается через ~0,3–0,4 с.
- Расход на колонке: ~7 МБ памяти, ~3 % одного ядра при открытой странице.
- Состояние не сохраняется: после перезапуска агента подсветка снова у прошивки.
